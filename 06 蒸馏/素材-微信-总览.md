## 语言指纹摘要

- **短句为主**：中位句长 **5 字**，58% 的消息 ≤5 字，只有 2.4% 超过 50 字
- **标点习惯**：逗号为主（8,689），句号 3,610，顿号 3,591；括号补充说明 1,746+1,229；引号用得不少
- **emoji 克制**：✅🍺🐟😡🦍 是高频组合，总量远低于文字
- **口头禅候选**：可以 / 没有 / 哦哦 / 这个 / 哈哈 / 不是 / 数据 / 我们 / 好的 / 要的 / 捂脸
- **高频开头**：「我觉得」「这个」「可以」「不是」——先表态再展开

## 证据分级

- 微信原话 = **`verbatim` 最高级证据**，可直接引用（引用时标 `#证据/verbatim` 并注明会话代号）
- 从消息频率/长度/标点统计出来的结论 = `artifact`
- 对某人的关系判断 = `impression`（放在分隔线以下的印象区）
