# 访谈-总题库

> 7 轮访谈，把 immortal-skill 的四个提取器翻译成「问人话」。
> 原则：**问行为，不问形容词**。「你是个有条理的人吗」没用；「你手机备忘录里现在有几条没做完的清单」有用。

## 第 1 轮 · 身份基底 + 语言母语样本

1. 你怎么称呼自己？年龄阶段、城市、现在的身份（学生/工作/在准备什么）——用你自己会出口的那句话介绍。
2. **贴 3–10 条你自己发出去的原话。** 微信消息、朋友圈、群聊发言、日记、跟朋友吐槽都行，越长越好。这是 `verbatim` 的唯一来源。
3. 说话默认偏：长文 / 短句？结构化（分点） / 想到哪说到哪？正式 / 网络梗？
4. 你的口头禅、语气词、emoji、标点习惯是什么？（例：爱用「…」「哈哈哈」「emm」「（）」补充说明）
5. 一急、一生气、一开心，说话会变成什么样？
6. 别人最常用来形容你的 3 个词？你自己会用的 3 个词？
7. 最近在忙什么、在学什么、烦什么？

## 第 2 轮 · 说话指纹

1. 解释一个你不懂的概念时，你第一步会干嘛？（举例 / 类比 / 先反问 / 直接说不知道）
2. 你会用哪些类比？举 2 个你真用过的。
3. 打字用什么输入法、多快、爱不爱改错字、发完会不会撤回？
4. 回复节奏：秒回 / 隔几小时 / 看人？哪种人你会秒回？
5. 你什么时候会从「随意」切成「正式」？切换的信号是什么？
6. 你夸人和骂人分别怎么说？各举一句原话。
7. 你有没有很讨厌别人对你用的说话方式？（例：一上来就「在吗」）

## 第 3 轮 · 价值观与底线

1. 做选择时，什么因素排第一？（钱 / 时间 / 关系 / 自由 / 面子 / 成长）
2. 有没有一句话是你反复信、而且真按它做过决定的？
3. 什么事你会立刻翻脸，没有商量余地？
4. 你最近一次「明明吃亏但没后悔」的决定是什么？
5. 你怎么判断一个人「靠谱」？三个具体信号。
6. 你怎么判断一件事「不值得做」？
7. 你现在相信、但三年前的你不相信的事是什么？反过来呢？

## 第 4 轮 · 程序性：你怎么把事做完

1. 拿到一个任务，最先做的是哪一步？（列清单 / 先聊清楚 / 先做最小版本 / 先查资料）
2. 你常用的工具有哪些？工作、生活、学习分开说。
3. 你的笔记/文件是怎么组织的？现在还在用的方法是哪个？
4. 什么样的交付物你觉得「能交出去」？举一个你自己做过的满意的。
5. 你反复纠正别人的是哪类问题？（格式、逻辑、错字、不验证）
6. 决策靠什么：数据、直觉、问人、还是先做了再说？举一个真实的。
7. 什么情况下你会停下来找人确认，而不是自己决定？
8. 有没有「千万别这么做」的清单？谁踩过你的雷？

## 第 5 轮 · 互动与冲突

1. 有人给你一个你不认同的方案，你的第一反应说什么？（原话）
2. 你什么时候会推回去？措辞是什么？
3. 你质疑别人时，是直接说还是绕着说？
4. 吵架/冷战的时候你是什么模式：当场吵完、走开冷静、还是憋着？
5. 你怎么收场？谁先低头？
6. 你绝不做的沟通类型是什么？（已读不回？甩脸？阴阳？）
7. 别人难过时你怎么安慰？会说「没事的」还是先听完？

## 第 6 轮 · 记忆

1. 人生有哪几个明显的「之前/之后」？各用一个词概括。
2. 每个转折的触发因素是什么？你当时怎么评价这个决定？
3. 你有没有一个讲了三次以上的故事？完整讲一遍。
4. 有没有同一件事，你和你朋友的版本不一样？
5. 哪些话题你一聊就来劲？（❤️）
6. 哪些话题你会绕开？（🚫 只标注，不深挖）
7. 你的成长环境给你留下了什么？家庭、城市、学校，各一条。
8. 有没有一件「还没做完、还惦记着」的事？

## 第 7 轮 · 关系、技能、世界观

1. 对你影响最大的三个人？各一句话说清「他/她改变了你什么」。
2. 你擅长什么？别人会来找你帮什么忙？
3. 你有一套自己的行话/黑话吗？（领域词典）
4. 你怎么看这个世界？三个你坚持的判断。
5. 你现在的专业/兴趣领域里，你最看不惯什么？
6. 你有什么一直没搞懂、想问的问题？
7. 核对：[[矛盾-待裁定]] 里挂着的条目，逐条裁一下。

## 提问纪律

- 一次最多 7 题，等答完再下一轮，不要一口气灌 56 题。
- 用户答得笼统就追问一次具体例子；追问不到就标 `材料不足`，不要编。
- 答案先落进本目录的 `访谈-第 N 轮记录`（第 1 轮已建：[[访谈-第1轮记录]]），再拆进维度笔记，两边都要留链接。
