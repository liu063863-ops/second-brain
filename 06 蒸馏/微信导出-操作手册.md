## 3. 你要做的两步

### 第 1 步：手机历史 → 电脑（官方、零风险）

手机微信 → 我 → 设置 → 通用 → 聊天记录迁移与备份 → **迁移** → 迁移到电脑 → 选会话。

- 是「迁移」不是「备份」（备份是加密包）
- 只迁**当前登录**的那个号，4 个号要分别登录分别迁
- 迁移不删手机记录；迁移后 `message_0.db` 应涨到 MB 级

### 第 2 步：登录微信 → 跑导出

登录**你想导的那个号**（key 是账号级的，4 个账号 4 把 key），然后：

```powershell
# 双击也行：tools\keeper\export-wechat.cmd
tools\keeper\export-wechat.cmd -ProbeOnly          # 先看环境
tools\keeper\export-wechat.cmd -Method passive     # 只读内存，风险最低（新版多半取不到）
tools\keeper\export-wechat.cmd -Method active      # 启动被调试的微信子进程，需扫码，风险中–偏高
tools\keeper\export-wechat.cmd -Days 3650          # 默认 auto：passive 失败自动转 active
```

- `passive`：只读进程内存，不注入、不 hook、不附加调试器。
- `active`：会**先关掉现有微信**，再拉起一个被调试的 `Weixin.exe`，在 WCDB 的密钥派生函数下 INT3 断点捞 key，需要你在那个窗口扫码登录。
- 拿到 key 后缓存在 `%LOCALAPPDATA%\chatlog-keeper\data\secrets\`，之后导出直接复用，不用重复取。

## 4. 多账号的坑（你正好踩得上）

4 个 `wxid` 目录 + 账号级 key，如果 HMAC 校验库（oracle）选错账号的 `message_0.db`，表现是「登录窗口一直等到超时也没拿到 key」。解法是绕开编排层，直接指定库：

```powershell
powershell -ExecutionPolicy Bypass -File `
  tools\downloaded\chatlog-keeper\chatlog_keeper\scripts\windows_wechat_get_key.ps1 `
  -DbPath "C:\Users\liujinhao\Documents\xwechat_files\<目标wxid>\db_storage\message\message_0.db"

# 拿到形如 "master key: <64位hex>" 后喂给 keeper：
tools\keeper-venv\Scripts\python.exe -m chatlog_keeper.cli set-key --source wechat --key-stdin
```

另一个坑：新版 `Weixin.exe` 只是启动器，真正的 `Weixin.dll` 在版本号子目录里（如 `C:\Program Files\Tencent\Weixin\4.1.15.13\`），脚本默认会按注册表找，自定义安装路径时要显式传 `-WeixinDllPath`。

## 5. 导出产物 → 我接手

导出得到 `wechat_messages.json` + 一个怀旧风 `wechat_messages.html`。把 **JSON 路径**发我，我跑：

```powershell
python tools\wechat_ingest.py "<导出目录>" -o wechat-ingest
```

得到 `self-said.md`（只含我说的话，verbatim 池）、`fingerprint.md`（标点/emoji/句长/口头禅候选）、`messages.jsonl`，再按 `verbatim` / `artifact` / `impression` 分级拆进 [[性格-口头禅与语言特征]]、[[互动-默认沟通方式]]、[[性格-情绪模式]]。

## 6. 风险与红线

| 操作 | 封号风险 | 说明 |
|---|---|---|
| 读本地数据库文件 | ≈0 | 纯文件读取，不碰网络 |
| `passive` 内存扫描 | 低 | 社区长期采用，未见因此封号的实证 |
| `active` 调试器取 key | 中–偏高 | 会重启微信、附加调试器；只在 passive 失败时用 |

- **不联网不上传**：keeper 全程本地，零遥测。
- **脱敏**：聊天记录含他人发言，进库前把对方改成代号；导出文件本身别上传云端。
- **DMCA 是项目风险**：下架针对仓库，不针对你导出自己的数据。
