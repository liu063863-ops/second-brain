# 证据-标注规则

> 分身最容易烂的地方不是「知道得少」，而是「把印象当成事实」。这个页面是防烂阀。

## 一条结论的标准写法

```markdown
- 结论本身（一句人话，不写形容词堆砌）—— 证据原文或行为描述（`verbatim`，来源：微信 2025-03 与家人对话） #证据/verbatim
```

三个成分缺一不可：**结论 + 证据 + 级别与来源**。

## 三个级别怎么判

### `verbatim`
- 你能指出具体哪句话、哪条消息、哪篇自己写的文章
- 判据：能截图、能引用、能定位
- 允许有错别字、口语、脏话——原话越糙越可信

### `artifact`
- 从你的作品/文档/行为里客观推断，但找不到「原话」
- 例：「连续三年在同一个笔记本里记周计划」（从行为推断有条理）
- 写清楚推断依据：`（`artifact`，依据：2023–2025 三个手账本）`

### `impression`
- 你自己或别人的主观判断：「我觉得我挺随和的」「朋友说我很轴」
- **不允许出现在正文区**，一律放到文件末尾 `---` 以下的「印象区」
- 必须注明是谁的印象：`（`impression`，来源：本人自评 / 朋友 A）`

## 反例清单

| ❌ 错误写法 | 为什么错 | ✅ 改成 |
|---|---|---|
| 我是个完美主义者 | 心理标签，不可观测 | 交付前会反复改同一段文案，平均 3 遍 |
| 我性格内向 | 标签 | 群里很少发言，私聊会连发十几条 |
| 朋友都说我靠谱 | 无来源印象混入正文 | 正文删掉，印象区写：`（`impression`，朋友 A）` |
| 我比较理性 | 通用形容词 | 买东西会比价 3 个平台，但选餐厅凭直觉 |

## 材料不足怎么写

直接写 `材料不足`，并注明缺什么素材。**不要用常识填坑**——「程序员一般都爱喝咖啡」这种不是你的特色。
