# 朋友圈-覆盖范围与补全

> **状态：已补全（2026-10-25）。** 在 PC 微信把朋友圈滚到第一条之后，本地缓存从
> 57 条 / 2026-01 起，扩展到 **306 条 / 2018-02-26 起**。

## 一、补全前后对比

| 指标 | 补全前 | 补全后 |
|---|---|---|
| 时间线缓存条目 | 509 | **768** |
| 我的帖子 | 57 | **306** |
| 最早一条 | 2026-01-28 | **2018-02-26** |
| `sns.db` 大小 | 6.5 MB | **10.9 MB** |

## 二、为什么之前缺

本地 `sns.db` 只是**客户端缓存**，不是备份：

1. 朋友圈按页向服务器拉取，**不滚就不拉**，本地只有第一页
2. 「迁移聊天记录到电脑」**不包含朋友圈**
3. 缓存会被清理（换设备/重装会从最近一页重新累积）
4. 服务器不开放导出接口

## 三、这次是怎么补上的

1. 你在 PC 端打开朋友圈，一直往下滚到 2018 年第一条
2. 客户端把拉到的页写入 `sns.db`（6.5 MB → 10.9 MB）
3. 我用 master key 重新解密，提取全部 306 条

> 结论：**朋友圈可以补，前提是客户端真的拉过一遍。** 以后换电脑，先滚到底再备份这个库。

## 四、仍然缺的

- 图片原图（只有数量，没导出媒体文件）
- 朋友圈的点赞/评论互动（本机缓存里我发出的评论为 0，可能是没同步）
- 更早的 2018 年以前（那时可能还没用微信）
