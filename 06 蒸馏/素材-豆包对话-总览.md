## 二、你怎么指挥 AI（最有信息量的部分）

| 特征 | 原话 |
|---|---|
| **极短、祈使句、不寒暄** | 「配置这个密钥并重启codex」「关闭检测」「读取这个项目，分析其」 |
| **给现场证据，不给描述** | 直接贴报错原文：「unexpected status 401 Unauthorized: {"code":"INVALID_API_KEY"}」；连续上传两张截图 |
| **要可执行的结果，不要解释** | 「请直接指出图片里的问题，并给我完整的、可以直接复制替换的 mine.wxml 和 mine.js 代码」 |
| **讨厌敷衍，要求诚实** | **「如果做不到，直接说做不到。」** |
| **会反复迭代细节直到对** | 客服悬浮球尺寸 88rpx → 76rpx → 60rpx，连问三次 |
| **要求「零配置」交付** | 「帮我调整到只要接入api这个功能就能使用的状态」 |

> 「如果做不到，直接说做不到」——这一句和 [[性格-核心价值观]] 里的「讨厌被骗 / 讨厌装」是同一件事：
> **他要的是能落地的答案，不是漂亮的答案。**

## 三、暴露出的技术栈

| 类别 | 具体 |
|---|---|
| AI 编码 | Codex CLI（config.toml、auth.json、model_providers、MCP 服务器） |
| API 中转 | SpeedyAPI、clawtkcn（密钥管理、余额、502/401/403 排查） |
| 浏览器自动化 | Playwright MCP（@playwright/mcp）、Edge |
| 小程序 | 微信原生 + TDesign 组件库、开源开发者工具、AppID/客服配置 |
| 后端 | Django + DRF、PostgreSQL / SQLite、Celery / Redis、8000 端口 |
| AI 能力接入 | 华为云 OCR + 大模型、DeepSeek API（意图路由、推荐叙事） |
| 系统 | Windows 环境变量、PowerShell、磁盘空间治理、任务计划/cron |

## 四、能看到的能力

- **能独立把项目跑起来**：项目分析、定位根因（编码问题、flex-shrink:0、button 默认 size）、修路由 404
- **不止写代码，还管环境**：密钥、网关、依赖、缓存、编码、端口
- **有产品意识**：IP 形象「猴学长」、首页动态问候语、客服直连微信
- **务实到极致**：把 MySQL/Redis 改成「没配就用 SQLite/内存缓存」，让项目零配置能跑

## 五、项目背景（新事实）

**第十一届华为 ICT 大赛参赛项目「重人科 AI 智慧校园助手」**：
微信小程序（46 个页面）+ Django 后端，含驾校报名、跳蚤市场、出行服务、零食购买、校园网、兼职信息、跑腿服务、学术服务八大模块；
AI Agent 接华为云大模型做意图路由，跑腿抢单用数据库原子 CAS。
