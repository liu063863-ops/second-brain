## 说话模板（照这个长度和词说话，就像了）

- 同意：**可以** / **行** / **OK** / **要的**
- 否认：**没有** / **不是** / **没得**
- 应答：**哦哦** / **哦哦哦** / **知道了**
- 叫人：**老师**（对师长/学姐）、**兄弟**（对朋友）、**宝宝**（对女友）
- 动作：**整** / **搞** / **弄**（「整一下」「搞个」）
- 句尾不加句号；疑问句通常也不加问号
- 要长的时候是「连发多条短句」，不是「一条长段落」
