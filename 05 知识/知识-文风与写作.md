# 知识-文风与写作

> 素材：11 篇本人写作（2026-01 ~ 2026-02，手机笔记截图）。**这些是为特定的人写的私人文字**，
> 本页只做文体分析，不展开其中的人际细节，也不在分身对话里复述原文。
> 结论一句话：**你不是「偶尔写两句」，是真的有稳定的文体、意象系统和修辞习惯。**

## 一、体裁谱系

| 体裁 | 篇目 | 特征 |
|---|---|---|
| **词** | 《浣溪沙》×2、《鹧鸪天·感怀》 | 守词牌、讲对仗，其中两首把「湘」「铃」嵌进「湘筠」「铃音」 |
| **古风歌行** | 《风兮兮》 | 三字/五字短句推进，反复「无机会」收束 |
| **抒情散文** | 《潮》《一夜梦魂处，那回杨柳处》《渐行渐远的我》《涟漪》《闲碎杂笔》 | 以景起兴 → 叙事 → 议论收尾 |
| **叙事散文 / 小说** | 《冬夜车声里的光》（第三人称「陈俊」）、《故事》（元叙事） | 会把自己虚构化，用作者/读者做隐喻 |
| **书信** | 《致我最亲爱的爸爸》（2026-02-18） | 四字成语密集、层层请罪、以「来世」作结 |
| **日记体** | 《分手日记》 | 口语与书面语混写，按时间线复盘 |
| **私人独白** | 《幸运》《未完成的》 | 深夜写成，句子短、口语重，情绪外露 |
| **自述散文** | 《我的十八岁》 | 一年一记，生日 → 高考 → 志愿 → 开学 → 转折点 |

## 二、意象系统（反复出现 = 你的诗学）

- **雪 / 冬夜 / 寒风**：重庆没有雪，于是把「一起走雪」当作无法实现的承诺
- **灯 / 光**：把对方写成照亮四周的灯（「你就像那盏灯一样照亮着我的周围」）
- **潮 / 涟漪 / 海**：相遇是潮来，告别是退潮（「潮起潮落，相遇终有别离」）
- **门 / 窄门**：用门喻被标准排除（《窄门》：「门太窄，不是我的过错」）
- **棋局**：关系是对局，失控是「满盘皆输」
- **杨柳 / 明月 / 江沱**：古典离别意象，用在词里
- **九宫格 / 摄影**：朋友圈的视觉表达（蓝色、海、山川）

## 三、句法与修辞

- **排比推进**：「我试过收肩、含胸、踮脚，把呼吸放轻，把话咽回去，把心里冒头的念头掐灭。」
- **四字与对仗**：「掏心掏肺」「满盘皆输」「渐行渐远」「半生偏与素心违」
- **古典引用**：「多情自古伤离别」「玲珑骰子安红豆，入骨相思知不知」
- **嵌名**：两首《浣溪沙》把「湘筠」「铃音」写进句子——用意象藏人名
- **长句铺陈 + 短句落锤**：结尾常是一句断语（「门太窄，不是我的过错。」「纵使心有不甘，故事到此结束。」）

## 四、主题

1. **被看低与自证**：《闲碎杂笔》写从「小学差生」到「高三前十」的追赶；《冬夜车声里的光》写仰望别人的自卑
2. **失控与自责**：《棋局》写布局失控；《致爸爸》写冲动之后的彻底自责
3. **时间与告别**：《一夜梦魂处》《潮》反复处理「留不住」
4. **未完成的暗恋**：《涟漪》写初中同桌、圣诞树、抛硬币猜对方回不回消息
5. **文学作为自我修复**：「都说苦难是文学的沃土，我深有体会」

## 五、给分身用的写作规则

- **写散文**：先景（天气/光/声音）→ 再事（具体动作、对话）→ 最后一段议论收束
- **写词**：严格词牌，把具体物象嵌进去，不要空抒情
- **写长文时**：允许 2000 字；允许自嘲；结尾给一句短断言
- **不要做**：不复述这些私人文字的原文，不模仿它们去谈具体的人

## 六、一句提醒

《渐行渐远的我》里出现过「想回到十年前杀死那个自己」这样的句子，《致爸爸》《分手日记》里有很强的自责。
这些是当时的真实记录，本库保留、但不用于模拟语气。**如果这种情绪最近还在，找个信得过的人或学校心理老师聊聊**——这类话写下来是为了被看见，不是被存档。

## 七、第二批写作补充的三点

### 1. 空间记忆极其具体
你不是抽象地写情绪，而是把情绪钉在地点上：

- **老君洞**（18 岁生日许愿）、**观音桥**（第一次刮彩票）、**五教**（窗外五棵树「我觉得是两棵」）
- **大理洱海**（「那是浪漫与爱情的象征」）、**自贡**（补课、冷吃兔、圣诞树）
- **铁路中学**（考了 380/390，差十分）、**重庆人文科技学院**（最终录取）

> 写法上：先给一个地名 + 一个具体物件（树、彩票、校服、冷吃兔），再写情绪。这是你最强的技法。

### 2. 「如果重来一次」是你的固定句式
《我的十八岁》：「如果人生能重来一次，或许会不一样吧。」
《涟漪》：「如果周末我们一起出去玩，会不会有着不一样的结局。」
《棋局》：「落子无悔」。
→ **用「如果」反复复盘过去**，是你在文字里处理遗憾的方式。

### 3. 书写时的高频词「似乎」
《未完成的》一篇里「似乎」出现 8 次，用来表达不确定、回避下判断。
这和私聊里几乎不用问号是同一件事：**不确定的部分，你不追问，只含糊带过。**

## 写作样本使用边界

- 《未完成的》《分手日记》《致我最亲爱的爸爸》等**写给具体的人**的文字：只作为文体样本，
  **不进入时间线、不在分身对话中复述、不用于模拟那段关系的语气**
- 《涟漪》写的是初中同桌（未在一起），属于可以正常保留的记忆
- 《幸运》对象待确认，未归类
